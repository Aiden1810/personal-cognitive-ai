# 知衡 · Personal Cognitive AI

知衡是一个以聊天为入口的个人 AI 项目：从对话和用户提供的经历中形成有依据的当前画像，让用户确认并选择希望保持或改变的方向，再在后续对话和决策中提供针对性帮助。完整定义见[产品方向](docs/product-vision.md)。

这是澳门城市大学创新比赛项目，团队成员为安、姚、曹。产品方向已在 2026 年 9 月 28 日调整；此前的“三视角决策”页面保留为[旧演示资料](docs/legacy-decision-plan.md)，不再是第一版主流程。

## 第一版目标

**聊天 → 七维框架下的候选洞察 → 用户核对当前画像 → 用户设定目标画像 → AI 按当前状态与目标辅助。**

参考 Digital Twin v2 的七个维度组织资料，但首版可只做其中一条可验证的完整流程。每条判断都要能查看来源和审核状态；用户可以编辑、删除，并决定是否让它参与后续回答。当前画像与目标画像分开保存；不做心理诊断或未经定义的人格百分比分数。

## 当前实际完成的部分

- `/chat` 是首页：可新建、选择、删除本地对话，保存双方消息，刷新后保留。
- 浏览器存储出现错误时显示提示，不能悄悄清除已有资料。
- 原 `/history`、`/goals`、`/decision` 页面仍可从“旧版决策演示”进入，作为历史原型参考。
- `/chat` 已连接本地开发用的 `/api/chat` 服务端接口；配置自己的 `LLM_API_KEY` 后默认请求 DeepSeek Flash 并保存回复。2026 年 9 月 28 日已通过一条不含个人资料的真实短消息验证连通。缺少密钥或请求失败时会显示错误、保留原消息并允许重试。
- `/chat` 中可主动点击“从这段对话提取候选”：DeepSeek 只根据当前对话的用户消息提出最多 3 条带原话证据的七维画像候选。用户可查看、修改、确认、驳回或删除；只有确认且来源仍存在的洞察会传入后续聊天。删除对话会清除由它产生的洞察。
- 画像目前也只保存在当前浏览器。提取需要用户主动点击，不是后台自动学习；尚无独立画像总览、矛盾检测、目标画像、登录或数据库。

现在的数据只在当前浏览器中。清理浏览器数据可能使对话丢失，也无法跨设备同步；请先用虚构或脱敏内容测试，不要输入真实敏感资料。

## 本地运行（Windows PowerShell）

需要 Node.js 24 和 npm。首次获取代码后，在项目目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端显示的 Local 地址，首页会进入 `/chat`。如果需要换端口：

```powershell
npm.cmd run dev -- --port 3001
```

验证命令：

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

`npm.cmd ci` 按锁文件安装 Next.js（Web 框架）、React（界面）、TypeScript（类型检查）和 ESLint（代码检查）。聊天存储使用浏览器原生能力，无需额外安装库。ESLint 暂锁定 9.39.5，以兼容当前 Next.js 附带的 React 插件；npm 可能提示该版本停止支持，后续由安统一升级。

如需本地测试真实 AI 接口，在项目根目录执行 `Copy-Item .env.example .env.local`，只在 `.env.local` 填写 DeepSeek API Key，然后重启开发服务。密钥只由服务端读取。接口在 production 环境暂时关闭，避免缺少登录与防滥用措施时公开消耗额度。接口格式与字段见[团队交接](docs/team-handoff.md)。

`LLM_MODEL` 默认是 `deepseek-flash`。模型变更后重启开发服务。测试提取时可用虚构消息：发送一句话，展开“画像候选与审核”，点击提取，核对原话后确认，再发送下一条消息。
