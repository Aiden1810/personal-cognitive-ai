# 知衡 · Personal Cognitive AI

知衡是一个以聊天为入口的个人 AI 项目：从对话和用户提供的经历中形成有依据的当前画像，让用户确认并选择希望保持或改变的方向，再在后续对话和决策中提供针对性帮助。完整定义见[产品方向](docs/product-vision.md)。

这是澳门城市大学学生为参加 **2026 年第十一届「粤港澳大湾区 IT 应用系统开发大赛」澳门区分赛**而开发的项目，团队成员为安、姚、曹。产品方向已在 2026 年 9 月 28 日调整；此前的“三视角决策”页面保留为[旧演示资料](docs/legacy-decision-plan.md)，不再是第一版主流程。

**第一次接手或要把背景发给其他 AI：**先看[项目背景、比赛要求与 AI 快速交接](docs/project-context.md)。其中集中说明项目用途、当前边界、文档和代码入口，以及邀请函逐页核对的比赛要求。

2026 年 10 月 7 日更新：当前由安独立负责开发和比赛材料，其他成员的新任务暂停。简报即同一份比赛 PPT：10 月 15 日前更新并提交给主办方，15 日后不能再改，24 日使用这份最终版路演；当前安排见[路演准备](docs/contest-roadmap-2026-10-24.md)。

比赛邀请函要求项目简报 PPT **10–15 页**，可选介绍视频 **2–5 分钟**；澳门分赛在 **10 月 24 日 10:00–13:00**举行，决赛为简报加答问。原函的报名及首次作品提交截止为 **10 月 1 日**，上面的 15 日安排来自安确认的后续 PPT 更新要求；不能据此声称报名截止延期。评分权重、单队时长和后续更新渠道尚需核实，见[比赛背景与来源](docs/project-context.md)。

## 第一版目标

**可选首次问卷 → 聊天 → 五项具体行为画像与来源 → 用户核对当前状态 → 用户设定目标 → AI 按相关状态与目标辅助。**

2026 年 10 月 11 日，安确认将主界面收窄为行动力、规划与拆解、时间安排、复盘调整、探索尝试。旧七维资料与目标保留在“其他背景与旧资料”，不自动转换成新档位。每条判断都要能查看来源和审核状态；用户可以编辑、删除，并决定是否让它参与后续回答。当前自评与目标档位分开保存；不做心理诊断或人格测量分数。

- `/chat` 的“对话设置 → 对话记忆”中可点击“整理这段对话”：最多读取最近 20 条用户发言、合计 2 万字符，“使用范围”显示实际读取和未包含的条数；助手回复不占用提取额度。DeepSeek 提出最多 3 条带原话证据的画像候选，主界面按五项行为组织，旧七维保留为其他背景。聊天页只展示待确认的新发现，可记住、忽略、修改或删除；已审核记录在“我的画像”管理。删除对话会清除由它产生的洞察。
- 提取时会附带这批原话相关的最多 30 条已有候选与审核记录，提示模型避免重复提出或换句话重提已驳回的判断；代码还过滤同维度、仅标点等差异的重复描述。语义去重仍依赖模型，不保证完全消除重复。
- 聊天只使用确认且来源仍有效的洞察：中英文词项和有限主题词匹配画像描述，原话旁支话题不单独触发召回。零匹配不补满；明确追问可参考最近用户发言，新话题不继承旧主题，助手发言不提供检索主题。每次最多 5 条画像、2 项相关启用目标，保留所选完整原话，实际附加资料 JSON 最多 3,000 字符。其余本地记录不删除；这不是向量语义检索。明确中文请求“不要参考……画像”可排除本次长期画像，目标仍单独筛选。
- `/chat` 可在“对话设置”中展开“这次参考的记忆”，查看选择结果、原话与关联原因。它展示请求附带资料，不代表模型一定采纳；匹配技术说明收起，只保留本页最近请求的展示。

- `/profile` 主导航为五项具体行为，保留“当前的我 / 我的目标”并排布局。确认且原话有效的记忆构成当前画像；待确认记录提供原话与记住/忽略操作，其他审核状态仍可查看。去掉重复说明，原话与范围在详情中查看，不打人格分数。
- 2026 年 10 月 8 日：画像记录可区分一次经历、近期状态、自述偏好与自述习惯；旧记录显示范围未标注。提取提示要求保留具体情境、行为和结果，并用有限词项过滤没有反复表述依据的习惯推断；不保证语义判断完全正确。界面显示原话条数和最近原话日期，条数不是独立事件数量或置信度。
- 新候选可由用户主动选择同维度已确认旧记忆，核对双方原话后确认更新：新记录确认、旧记录归档，保留历史依据。用户也可单独归档已经不适用的记录；归档退出当前画像参考，原始聊天仍保留，可重新核对启用。仍无自动冲突判断、证据合并或时间衰减。
- `/chat` 的“对话设置 → 回答偏好”可保存回答长短、解释方式与回答结构，刷新及新建对话后仍保留；每次请求应用，不受画像关键词检索影响。当次明确要求优先是模型提示规则，不是强制输出格式验证。偏好纳入本地/云端快照，旧备份恢复默认偏好，恢复写入失败仍倒序回滚。
- 每条已确认画像可设置“AI 帮助方式”（原回答适配程度）：低档直接给要点，中档补方法与例子，高档提供分步帮助、卡点与检查方法。仅被检索选中的画像会带上等级进入模型请求；旧记录默认中档，修改等级无需重新确认事实。它表示用户希望获得的帮助程度，不是人格或置信度分数；当次明确要求和全局回答偏好优先。聊天参考面板显示本次实际发送的等级，JSON 备份保留设置。模型输出仍需实际核对，操作与边界见[本轮记录](docs/superpowers/plans/2026-10-09-profile-response-adaptation.md)。
- `/profile` 每个维度可直接设置一个目标，并修改、暂停、启用或删除。目标与当前画像分开保存；只有启用且与本次提问相关的目标才发送给 DeepSeek。
- 目标编辑保留五档可选改变意愿，也可不设置：暂不想改变、稍微想改变、比较想改变、很想改变、当前最想改变。等级由用户选择，不表示问题严重程度或目标达成率；修改已暂停目标仍保持暂停。
- `/profile` 新增本地“综合观察”：用户可把已确认且来源有效的洞察标为想发挥的优势或想改善的地方，并把两条洞察及原话并排加入核对列表。它是用户自己的整理，不是 AI 自动得出的诊断或矛盾判断。
- `/chat` 可在“对话记忆”中主动开启“自动整理新记忆”：开启时以当时发言为起点，此后每新增 4 条用户发言，在 AI 成功回复后按现有提取上限自动调用 DeepSeek Flash。结果仍是待审核候选；默认关闭，失败会提示，不会生成假资料。
- 聊天页默认收起设置，移除重复存储说明、旧版入口和消息计数；空对话不占列表位置。“新对话”会复用已有空对话。右键某条对话、按 Shift+F10 或通过标题旁的“⋯”打开菜单可删除该段对话，删除前保留确认；回复请求过程中禁用删除。存储及模型使用范围说明集中在资料备份与记忆设置中。
- `/profile` 可点击生成 AI 综合观察草稿：把最多 20 条已确认且来源有效的画像描述、维度和原话摘录发送给 DeepSeek Flash，整理可能的优势、改善方向及值得核对的张力。每项展示所关联的画像和原话；草稿不保存为事实，也不用于聊天。
- `/progress` 已有本地行动记录与比较代码，页面完整流程尚未验收，不能宣称已验证的反馈闭环。其设计是把一次实际选择、观察结果和用户自评关联到当时的文字目标；修改目标后旧记录仍保留原目标文本。同一目标记录至少 6 次后会比较最近 3 次和之前 3 次的自评。概况数字与比较结果只反映用户记录，不代表自动测出的改善程度。
- 界面保留原来的导航、页面布局和功能位置，主要去掉英文分区及重复说明。行动页显示表单与历史，备份和账户直接展示操作区。用户澄清后的结构修正见[本轮记录](docs/superpowers/plans/2026-10-10-restore-page-layout.md)。
- 日常资料仍优先保存在当前浏览器。`/backup` 是独立本地备份入口，可下载、选择和校验 JSON，再主动恢复；不需要登录或云端配置，也不经过云端会话刷新。恢复会覆盖当前浏览器资料，自动提取会关闭；写入失败倒序回滚。`/account` 保留可选云端账户与快照入口，尚无逐条实时同步。自动提取不是后台长期更新；AI 综合观察是按需草稿，不是已验证矛盾检测。当前 UI 和材料由安负责。

未主动备份的修改只在当前浏览器中；清理浏览器数据会丢失这些修改。退出云端账户也不会清除当前浏览器资料，共享设备上不要保存真实私密内容。云端备份包含聊天原文与画像依据，测试阶段请先使用虚构或脱敏内容。

需要 Node.js 24 和 npm。首次获取代码后，在项目目录执行：

```powershell
. .\scripts\use-project-node.ps1
npm.cmd ci
npm.cmd run dev
```

打开终端显示的 Local 地址，首页会进入 `/chat`。如果需要换端口：

```powershell
npm.cmd run dev -- --port 3001
```

`npm.cmd ci` 按锁文件安装 Next.js（Web 框架）、React（界面）、TypeScript（类型检查）、ESLint（代码检查）、Supabase 客户端及 Transformers.js（本地语义模型运行）。向量模型文件不随 npm 或 Git 安装：首次使用实验前执行 `npm.cmd run prepare:semantic`，下载约135MB公开文件；已准备后推理禁止联网。日常资料仍用浏览器存储。ESLint 暂锁定 9.39.5，以兼容当前 Next.js 附带的 React 插件，后续由安统一升级。

如需本地测试真实 AI 接口，在项目根目录执行 `Copy-Item .env.example .env.local`，只在 `.env.local` 填写 DeepSeek API Key，然后重启开发服务。密钥只由服务端读取。接口在 production 环境暂时关闭，避免缺少登录与防滥用措施时公开消耗额度。接口格式与字段见[团队交接](docs/team-handoff.md)。

云端数据库使用单独的 Supabase 项目 `Zhiheng`（项目 ID `lfavqbsdhxmijfecddfa`，新加坡区域）。`database/schema.sql` 记录十张表与 Row Level Security（RLS，按账户隔离）的既有结构，历史记录称已经应用到该项目；不要在已有项目上重复执行建表脚本。`.env.local` 另需 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`，只使用 Supabase 的 publishable key，不能把 service role key 放进浏览器或 Git。本机这两项已配置，其他成员从安处获取各自的公开配置。访问 `/account` 创建账户并完成邮箱验证后，可手动备份、下载本地 JSON 或从云端恢复。恢复前会提示覆盖当前浏览器数据；建议先下载本地备份。邮箱验证已有实际成功记录；邮件回调自动登录与跨设备恢复仍需真实账户实测。逐条画像表仍保留旧七维约束；五项问卷随 JSON 快照保存，不等于新画像已逐条迁移到云端表。本轮清理未执行 SQL 或连接真实云端账户。

本地注册排错：确认邮件用于验证邮箱，验证成功与自动登录是两个步骤。手机上的 `localhost` / `127.0.0.1` 指向手机自己，不能打开电脑的本地页面；此外 PKCE 自动登录需要发起注册的同一浏览器。手机点邮件后页面打不开时，先回电脑 `/account` 用原邮箱和密码登录，不要重复注册。2026 年 9 月 30 日已通过只读查询确认一个实际注册账号的邮箱验证成功；完整备份恢复仍待实测。开发环境的 Supabase Auth URL Configuration 应将 Site URL 设为本地站点，并允许精确回调 `http://127.0.0.1:3001/auth/callback`（如使用 localhost，另加入相应地址）；这里记录的是配置要求，不表示已通过当前工具修改控制台配置。

`LLM_MODEL` 默认是 `deepseek-flash`。模型变更后重启开发服务。测试时可用虚构消息：在 `/chat` 发送一句话并手动提取候选；到 `/profile` 核对原话、确认画像、填写一个目标，再回到聊天发送下一条消息。暂停目标后，后续聊天不再使用它。也可以在 `/profile` 手动标记画像，并到 `/progress` 记录一次虚构选择和结果，刷新确认记录仍在。
