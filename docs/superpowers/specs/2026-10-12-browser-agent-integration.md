# 知衡 Browser Use 本地集成

安已授权继续：独立执行层接到知衡，先完成个人资料 → 计划 → 浏览器 → 候选 → 个性化整理 → 聊天回复的闭环。对比 Demo、录屏和 PPT 暂时搁置。

## 范围与架构

- 保留 Next.js 聊天、模型传输、画像/目标/偏好 Store、逐回复参考资料及原备份格式。
- Python FastAPI 单进程只监听 127.0.0.1:8001，管理单个在途 Browser Use 任务；短轮询显示真实事件，可取消。无数据库、队列、多智能体、登录、上传或支付。
- Next.js 创建计划和整理结果均使用 `requestModelCompletion`；Python 复用已验证的 DeepSeek 适配与独立浏览器配置。
- Next/Python 通过仅服务端读取的本地随机令牌通信。网页无法直接调用 Python，无 CORS；Next 接口沿用仅本地开发且同源的限制，production 禁用。
- 搜索入口为 Bing。初次实现限定五个资料站；2026-10-13 安授权放宽为不同网站的公开 HTTPS 学习资料，保留本地地址过滤和不登录、不提交表单、不上传或下载的操作范围。站点受阻时明确失败或仅返回已验证候选，不伪造结果。导航检查不等于完整网络沙箱。

## 数据与交互

- 聊天默认正常模式，用户主动选择“网页查找”后发送任务；提示会将本次背景、相关已确认记忆、启用目标和偏好发送给模型，并把必要搜索条件交给浏览器。
- 复用有效来源过滤与最多 5 条记忆、2 项目标、3000 字附加资料预算。资料检索补充明确的资料/学习偏好匹配；不从五项档位推导知识或英语水平，尊重停用与当次排除要求。
- 请求只含本次任务及选中资料，不读取全部历史。Python 只获得计划/筛选条件，不获得聊天备份或完整个人资料。
- 计划为 objective、queries（1–3 条）、criteria（1–6 条）。候选最多 5 条，最终最多 3 条；每条链接和摘录需与真实页面读取记录核对，标题取浏览器 metadata。
- 最终整理只引用已验证候选，不生成新链接。显示推荐原因及不能核实的限制；助手文字通过现有聊天 Store 保存，参考记录沿用已有契约。进度临时保留，不改存储格式。
- 不根据网页结果自动新增、确认或改写个人记忆和目标。
- 失败区分未启动服务、模型、浏览、超时、取消和结果整理。取消必须等 Python 清理后释放单任务槽；重复创建同一 requestId 不重复执行。整理失败保留已获取资源并可只重试整理。
- 单次浏览最多 15 步、240 秒，另有 20 秒清理预算。进度来自真实步骤/URL；不展示内部思考、不播放模拟进度。

## 验收

自动测试覆盖来源/排除、请求与计划校验、返回链接约束、同源/production 限制、服务鉴权、并发与幂等、取消清理、前端轮询/整理失败恢复。实际测试涵盖本地服务启动、真实计划、浏览搜索、个性化整理、聊天页面返回、取消与原聊天回归；使用合成背景，不读取真实个人资料。
