## 实施顺序

1. 公共布局：抽出共享 AppSidebar（参数 children、className），聊天页在同一侧栏放入现有对话列表；AppShell 的聊天模式不再重复侧栏和页头。公共颜色、字体、导航、表单和辅助页使用桌面样式覆盖层。
2. 聊天：保持原有读写和请求逻辑，合并侧栏，顶部提供参考资料与设置入口，候选记忆入口独立可见。助手正文取消卡片，用户发言保留浅色气泡；消息独立滚动，输入框始终可见。保留空、加载、失败、重试、候选审核状态。
3. 画像：五项行为改为横向按钮导航，当前自评与独立目标并排；将已确认记录与待确认候选明确分组，保留来源/修改/归档/删除及旧资料入口。背景与回答要求折叠展示，原存储与摘要行为保留。
4. 验证：既有 node 测试、typecheck、lint、build；浏览器验证 1366×768、1920×1080，无横向溢出、输入框可见、侧栏唯一、目标独立、候选审核/来源/编辑和失败重试可达。测试浏览器使用独立本地端口和合成数据，不覆盖用户日常资料。
