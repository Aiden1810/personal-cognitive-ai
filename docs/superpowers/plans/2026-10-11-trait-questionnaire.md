# 五项行为画像与首次问卷实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 用户已确认对话中的设计并要求直接修改；本次在当前功能分支增量执行，不提交、推送或部署既有未提交工作。

**Goal:** 用可跳过的 15 题问卷建立用户核对的初始画像，主界面展示行动力、规划与拆解、时间安排、复盘调整、探索尝试。

**Architecture:** 扩展现有画像、目标契约和同一存储入口，旧七维继续可读，不自动转换成新档位。问卷依据与聊天依据区分，回答、时间、版本和审核状态随既有备份保存；当前自评和目标档位独立保存。

**Tech Stack:** 现有 Next.js 16.3.6、React、TypeScript、Node test；不新增依赖。

**Spec:** 本对话中用户批准的五项特质、最近四周、统一频率选项、核对后保存、自由选择目标的方案。

## Global Constraints

- Windows PowerShell；保留他人和当前会话的未提交改动。
- 当前画像与用户目标分别保存；AI 不打人格分数，不自动升级档位。
- 问卷可跳过、不适用与不确定不计低档；无需模型或 API Key 即可填写。
- 用户确认保存才参与后续相关聊天；每条依据可查看、修改、归档、删除。
- 老备份兼容；恢复不重新启用自动提取；写入失败不破坏旧资料。

## Review Focus

- 没有答案、只有不适用时保持未知，不制造已确认事实。
- 重新填写时保留旧问卷历史，不替换聊天洞察或用户目标。
- 删除聊天不会删除独立的问卷依据；删除问卷画像后不继续引用。
- 旧七维资料和目标保留在“其他背景与旧资料”，包括只有目标的维度。
- 档位、自评、目标和帮助强度不能混用；请求预算包含新增字段。
