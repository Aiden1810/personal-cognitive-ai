# 图一：聊天页精简

按用户提供的截图和明确修改要求，保留既有配色及数据流程，精简聊天表面。

## 改动

- 公共导航去掉旧版决策演示入口，移除侧栏浏览器存储提示、顶部备份徽标及正式页面页脚。旧演示源文件保留作历史参考。
- 对话列表去掉英文标题、消息数量与存储说明；只显示已有消息的对话。点击新对话复用已有空记录，不自动删除历史资料。
- 顶部删除按钮移到对话行的右键菜单。按所点中的 ID 删除，不依赖当前选中 ID；继续调用已有聊天删除、关联画像清理和自动整理检查点清理。删除前继续确认，模型请求过程中禁用操作。
- 鼠标移到标题或用键盘聚焦时显示“⋯”；触屏始终显示。Shift+F10/菜单键可打开，Esc 返回标题，点外部、滚动或改变窗口尺寸时关闭。
- 回答偏好、检索设置、对话记忆及请求资料都归入默认收起的“对话设置”。有待确认记忆时才显示数量，没有零条占位。自动整理的普通状态放在设置里，失败仍显示在聊天页。
- 对话记忆仅展示当前对话待确认的新发现，提供记住、忽略、修改和删除；已确认画像在我的画像页管理。使用范围和读取数量收进次级说明，仍保留来源引用及确认门槛。
- 删除输入框底部快捷键及传输说明，隐藏可见标签但保留可访问名称；Enter 发送、Shift+Enter 换行行为沿用。

## 文件

- `src/components/app-shell.tsx`：导航、徽标及正式页面页脚。
- `src/features/chat/chat-workspace.tsx`：聊天布局、空对话列表、设置入口和删除目标。
- `src/features/chat/conversation-list-item.tsx`：右键菜单、其他操作入口及键盘操作。
- `src/features/chat/response-preferences.tsx`：入口名称。
- `src/features/profile/profile-review-panel.tsx`：简化记忆整理与审核显示。
- `src/app/refinement.css`：设置区域、菜单、空白页与响应式样式。
- `README.md`：同步当前入口和操作方式。

## 页面验收

本地服务已在 3010 运行时刷新 `/chat`；否则按 README 用 `npm.cmd run dev` 启动。

1. 检查旧版入口、存储说明、消息计数、右上角删除和底部快捷键说明已消失。
2. 多次点击新对话，确认列表不堆积空标题；发送第一条消息后列表显示其标题。
3. 建立两条合成测试对话，选中 A，右键 B。先取消删除确认，核对两段都保留；再确认删除 B，核对 A 和其正在编辑的文字仍保留。
4. 用 Esc、点外部、滚动和 Shift+F10 检查菜单；删除当前测试对话后页面仍能继续聊天。
5. 展开对话设置，核对回答偏好和自动整理设置仍保存；记住候选后在我的画像能看到。
6. 窗口缩窄时通过“⋯”操作，核对菜单不越出视口。

删除验收请使用专门生成的合成对话；本轮没有执行删除用户资料。
