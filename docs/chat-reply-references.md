# 每条回复的参考资料记录

2026 年 10 月 12 日。安确认在 AI 回复附近提供默认收起的参考资料，并在刷新后仍能核对。本轮在现有聊天、画像和备份入口上增量实现，没有新增项目依赖。

## 使用与边界

- 新回复下方显示“本次参考资料”，分别统计当时附加的记忆与目标。展开可查看对应提问、关联原因、记录时间、记忆原话、来源名称与日期，以及独立目标；提供进入画像页管理的入口。
- 标题的数量表示当时请求附加的资料，不等于模型实际采用了多少条。资料不是模型内部思考过程。
- 没有选中记忆与目标时明确显示“未附加长期记忆”；旧回复没有引用记录时显示“未记录”，不补造历史。
- 画像、目标修改、停用、删除或来源失效后，只提示相应历史引用不可用，不显示旧正文或用新正文替换历史内容。问卷来源按既有校验规则处理。
- 保留个人背景、自定义回答要求、快捷偏好是否附加的标记，不在历史引用里复制这些自由文字。匹配原因保留关键词、主题及语义命中标记，向量相似度不解释为事实置信度。
- 引用区使用原生 details/summary，支持键盘开合，延续现有尺寸过渡，并遵守系统减少动态效果设置。

## 数据契约

`ChatMessage.references?` 是版本 1 的可选引用记录，包含对应用户消息 ID、请求时间、检索方式、引用 ID、内容校验值、选中依据校验值、匹配原因和设置标记。回复与引用通过同一次 `appendMessage` 写入，写入失败时保留此前聊天；不会额外增加模型请求。

引用必须对应紧邻的用户提问，只能附加到助手回复。字段格式、数量、时间及重复 ID 在保存和读回时校验。损坏资料不静默清除。引用直接进入现有本地 JSON 与云端快照格式，存储键及版本不变；旧备份可以没有该字段。本轮没有验证真实云端账户流程。

引用记录不另存记忆描述、原话、目标正文或个人设置正文。显示时从当前有效记录解析并比较内容校验值。校验值只用于发现变化，不是加密或安全认证；删除画像不会自动抹去已存在的聊天正文。

每条引用组件使用 React.memo，输入草稿变化不重新扫描全部画像。空引用跳过画像扫描；画像、目标或聊天来源变化仍触发重新核对。

- `src/lib/chat/references.ts`：引用契约、校验、生成及有效内容解析。

- `tests/chat-references.test.ts`：保存与恢复、旧备份、错误来源、损坏记录、写入失败、正文不重复保存、修改删除与失效、选中依据及语义说明测试。
- `README.md`、本文：使用与验证说明。

## 运行与验证

```powershell
. .\scripts\use-project-node.ps1
npm.cmd run dev -- --port 3001
```

打开 `/chat`，发送与已确认记忆及启用目标有关的问题，展开新回复的参考资料；刷新后再次展开。随后在画像页修改、归档或删除记忆，再回到原回复核对不可用提示。旧回复应显示未记录；无相关资料时应显示未附加长期记忆。

自动检查入口：`npm.cmd test`、`npm.cmd run typecheck`、`npm.cmd run lint`、`npm.cmd run build`。

本轮新增 11 项引用测试；最终全套 292 项测试、typecheck、lint 和 production 构建通过。独立只读审查发现并修复语义原因遗漏和输入时重复解析问题，复核通过。浏览器使用独立 D 盘测试 profile、合成资料和明确模拟的 API 回复，核对默认折叠、逐回复独立记录、刷新、键盘、旧记录、空记录、失败不创建回复、390px 无横向溢出、减少动态效果和画像页实际删除联动。此验收不证明真实模型回答质量。

验收脚本与截图保存在本机忽略的 `output/playwright/reply-references-*`，不随仓库提交。本轮没有提交、推送或部署。

后续优先完善相关记忆选择与本次纠正处理；本轮没有扩大每次发送的资料量、接入个人模型训练或改造数据库。
